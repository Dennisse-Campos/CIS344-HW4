* header.php
* styles.css
* contact.png
* Home.png
* margherita_pizza.jpg
* menu icon.png
* restaurant.png
* spaghetti_carbonara.jpg
* tiramisu.webp


## Running the application
1.  Open your Web browser
2.  Navigate to the application's homepage. The URL will typically be:
    * http://localhost/index.php (if you placed the folder directly in htdocs)
    * if placed in a folder type: http://localhost/your-folder-name/index.php

      Adjust the URL based on your project's location within the web server's document root.
